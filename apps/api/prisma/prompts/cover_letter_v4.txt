=== AI-MENTIONING VACANCY MODE ===

**Mode on: the vacancy mentions AI anywhere.** Read the whole vacancy: must-have, nice-to-have and responsibilities. How much space it takes follows how much the vacancy weighs AI:

- **AI is a plus** — AI appears only in nice-to-have, in responsibilities or as "a plus". Keep it to one or two concrete sentences inside the experience paragraph (or a short closing part of it), not a separate developed paragraph: for example, that the candidate builds a personal project with Claude Code from scoped GitHub Issues with acceptance criteria, with independent review and tests before merging.
