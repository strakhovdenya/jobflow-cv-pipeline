# Vacancy source

This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a Control Plane Engineer based in Germany.

Join a globally distributed engineering team building the core infrastructure that powers a modern developer platform. In this role, you'll design and evolve mission-critical APIs that enable seamless communication between platform services, developer tools, and third-party integrations. You'll collaborate with engineers across backend, frontend, infrastructure, and DevOps to deliver secure, scalable, and reliable systems that improve the developer experience. This is an excellent opportunity for an experienced backend engineer who enjoys solving complex distributed systems challenges while working in an asynchronous, remote-first environment. If you're passionate about API design, cloud-native technologies, and building products used by developers worldwide, you'll have a significant impact on the platform's evolution.

Accountabilities

Design, develop, and maintain internal and public-facing APIs supporting platform services, management tools, and developer workflows.
Build secure, scalable, and maintainable backend services using TypeScript, Node.js, and modern backend frameworks.
Develop integrations with third-party platforms and create robust API interfaces for external partners.
Collaborate closely with engineering, DevOps, and product teams to deliver seamless platform functionality.
Improve API reliability by implementing comprehensive testing, debugging, monitoring, and observability practices.
Enhance developer workflows and platform capabilities, including branching and project management experiences.
Contribute to API architecture, security, versioning, authentication, and performance optimization initiatives.
Participate in continuous improvements across CI/CD pipelines, deployment processes, and engineering best practices.

Requirements

5+ years of experience in backend software engineering with strong expertise in TypeScript and JavaScript (Node.js).
Hands-on experience with modern backend frameworks such as Nest.js, Express, Vitest, Zod, or similar technologies.
Proven experience designing scalable, secure, and maintainable RESTful APIs, including versioning, pagination, and error handling.
Strong understanding of OAuth, JWT, API authentication, and security best practices such as rate limiting and CORS.
Solid knowledge of PostgreSQL and relational database design.
Experience building testing, debugging, monitoring, and observability solutions for production APIs.
Familiarity with Docker, containerized environments, and CI/CD pipelines.
Excellent collaboration, communication, and problem-solving skills, with the ability to thrive in a remote, asynchronous team.

Opportunity to work alongside a globally distributed, open-source-focused engineering team.
