# Vacancy source

Web Data Intelligence Platform



We are building an AI-powered web data intelligence platform that collects, structures, and analyzes information from public websites and documents.

The system processes messy real-world data from many organizations, extracts structured records from web pages and PDFs, stores them in a database, and presents them through a user-facing dashboard.

This is not a basic scraping role. We are looking for someone who can think across system architecture, data pipelines, AI extraction workflows, database design, and product usability.

The ideal candidate can take an existing MVP, understand the current logic, and help redesign it into a more scalable, configurable, and reliable platform.



What You’ll Work On



You will help build a system that can:

Discover and process public web pages, PDFs, and documents
Extract structured information from unstructured text
Normalize records into a database
Track updates over time
Detect duplicates, changes, stale records, and new records
Classify and score records using configurable rules
Match records to user-defined profiles
Support a dashboard for review, filtering, workflow, and feedback
Make the platform reusable across different use cases and industries


Required Skills



Strong fit if you have experience with:

Python and/or Node.js
Web crawling / scraping
PDF and document extraction
LLM-based extraction and classification
Database design
Full-stack development

Prompt engineering
Handling messy real-world data
Bonus experience:

Public web data
Search or monitoring systems
Workflow dashboards
Vector databases
Supabase / Postgres
Playwright
OpenAI / Claude APIs
LangChain, LlamaIndex, or similar tools

We are looking for someone who thinks in terms of:

Sources
Documents
