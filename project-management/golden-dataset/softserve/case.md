# Vacancy source

About The Role

In this role you will design and build scalable full-stack applications shaping architecture and delivering cloud-native tools that help retail teams detect stock issues, prioritize actions, and measure improvements in product availability. Our Client is a leading UK retail group operating supermarkets, convenience stores, banking services, and a major general merchandise retailer serving millions of customers nationwide. The project focuses on a strategic retail platform, combining operational and inventory data with modern UX to help stores identify stock discrepancies, understand causes, and improve on-shelf availability.

Responsibilities

Design, develop, and maintain scalable full-stack applications using Next.js, TypeScript, and modern web technologies
Own the quality, scalability, reliability, security, and maintainability of applications by contributing to architecture and technical design decisions
Collaborate with engineering team members by mentoring engineers and supporting continuous improvement initiatives across the team
Build server-side functionality, API routes, integrations, and data access layers within the Next.js framework
Develop intuitive user interfaces and operational workflows that support inventory accuracy and product availability initiatives
Design and implement integrations with inventory, replenishment, and enterprise operational systems
Work with NoSQL databases and large operational datasets to enable business-critical workflows
Design and implement cloud-native solutions leveraging Azure, AWS, Kubernetes, and Kafka-based architectures
Drive engineering excellence by performing code reviews, implementing testing strategies, and establishing CI/CD automation and development best practices
Troubleshoot and resolve complex issues across distributed systems and production environments


Requirements

6+ years of full-stack software development delivering scalable web applications
Strong expertise in Next.js, TypeScript, and JavaScript for modern full-stack development
Proven experience building full-stack applications within the Next.js framework
Experience in Node.js
Strong knowledge of Node.js runtime and backend capabilities within Next.js applications
Hands-on experience with non-relational databases such as MongoDB, Cosmos DB, DynamoDB, or similar NoSQL technologies
Practical experience designing and consuming RESTful APIs and integrating enterprise systems
Practical experience with cloud platforms, including Azure and AWS
Hands-on experience with Kubernetes and containerized application deployment
Practical experience with event-driven architectures and messaging technologies such as Kafka
Solid understanding of distributed systems, software architecture, security, scalability, and performance optimization
Hands-on experience with CI/CD pipelines, including GitHub Actions, and monitoring tools such as New Relic
Upper-Intermediate or higher English proficiency with the ability to communicate effectively with both business and technical stakeholders
