We are a team that builds applications with the latest technologies and works on meaningful projects. Our focus is on blockchain, AI, and other innovative areas. We are looking for a backend developer to help us take our products to the next level in an environment where we care about functionality, code quality, and developer experience.

Ready To Join?

Is this you? We hope so!

What You Will Do:

Develop backend applications with Nest.js
Design and implement APIs (REST and GraphQL)
Work with databases (PostgreSQL, Prisma/Drizzle ORM)
Optimize backend performance, security, and scalability
Integrate external APIs and services
Collaborate with the frontend team, DevOps, and QA
Contribute to architecture and technical design
Maintain high code quality using Prettier, ESLint, and test with Vitest
Manage and improve a Turborepo monorepo environment including build pipelines

Why We’ll Love You:

Experience with Nest.js
Strong knowledge of TypeScript, including build configuration and optimization
Experience with code quality and testing tools (Prettier, ESLint, Vitest)
Hands-on experience with monorepo setups (Turborepo, pipeline configuration)
Experience with databases (PostgreSQL) and ORM (Prisma/Drizzle)
Familiarity with Docker
