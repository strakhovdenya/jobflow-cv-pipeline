What You’ll Do (get Ready For Anything)

We're looking for a brilliant, curious, and proactive Mid-level or Senior Backend Developer. You'll help design and build services that deliver outstanding user experiences, taking full ownership of your backend work.

Backend development: TypeScript is your primary language. You'll build and maintain Lambda functions, ECS-hosted services, and REST APIs behind API Gateway — keeping them reliable, observable, and easy to evolve.
Event-driven architecture: You'll work daily with SNS and SQS to design async flows that handle audit results, trigger notifications, and integrate with external services. You understand idempotency, retries, and failure modes.
Container workloads: You're comfortable with Docker and deploying services via ECS/ECR, managing image lifecycles and task definitions.
Database management: You work across Aurora PostgreSQL and DynamoDB — schema design, migrations, query optimisation, and knowing when to use which.
Growing into infrastructure: As you settle in, you'll have the opportunity to contribute to our AWS CDK stacks and get hands-on with infrastructure as code — but this is a journey, not a day-one requirement.


What we’re looking for (spoiler: mental flexibility and creativity!)

Strong TypeScript skills: You write clean, well-typed async code and know how to keep a codebase maintainable as it grows.
3+ years of backend experience: You've shipped production Node.js services and know what production-ready really means.
AWS familiarity: Hands-on experience with at least some of: Lambda, SQS/SNS, ECS, API Gateway, RDS/DynamoDB.
Database foundations: PostgreSQL design and query optimisation are second nature to you.
Comfort with complexity: You thrive in technical challenges — distributed systems, async flows, complex integrations. They don't scare you; they energize you.
Ownership mindset: You raise problems early, follow through, and take pride in what you ship.


Bonus points (not mandatory, but nice to have!)

Curiosity about cloud infrastructure and a desire to grow into it — we use AWS CDK (TypeScript) and you'll have the opportunity to contribute to infrastructure as code alongside your backend work.
Familiarity with accessibility testing tools like Lighthouse or Axe.


If you’re asking yourself, “Is this the job for me?”, the answer is yes—if you love solving problems, building beautiful, useful things, and being part of a project that truly makes a difference. 💥
